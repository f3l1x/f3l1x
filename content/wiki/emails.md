# IMAP

Migrace mezi ucty:

```shell
imapsync   \
—host1 [imap.server.tld](http://imap.server.tld/)  \
—user1 [email@mydomain.tld](mailto:email@mydomain.tld)               \
—password1  “mypassword”      \
—host2 [imap.server2.tld](http://imap.server2.tld/)  \
—user2 [email@mydomain.tld](mailto:email@mydomain.tld)                \
—password2  “mypassword2”
```
